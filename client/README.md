# Albaplayer / client

## Scripts

- `dev` - install dependencies, start dev server and open browser
- `start` - start dev server and open browser
- `build` - build for production
- `preview` - locally preview production build
- `test` - launch test runner

## Stack

Created with /vite-template-redux

Uses [Vite](https://vitejs.dev/), [Vitest](https://vitest.dev/),
and [React Testing Library](https://github.com/testing-library/react-testing-library)
